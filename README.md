The scripts, automation ideas, how-to, and other assets in this repo cover DDLC use cases that I've fulfilled over the years - info gathering, autoring and publishing, maintenance, analytics, retiral and archival. 

The tasks included are asset extraction, path handling, filename validation, Markdown/MDX parsing, offline link checks, and frontmatter processing for SEO/AEO/GEO, and so on. The repo contains the scripts that I've used over the years. I frequently use PowerShell scripts and sometimes Python scripts. I create scripts with runtime inputs, robust quote/path handling, recursive processing, configurable exclusions and file types, forward-slash/root-relative paths when applicable, visible progress reporting, structured CSV/TXT output, focused regex/content parsing, useful section-level comments, and predictable behavior without inventing or modifying data beyond the stated requirement.

All scripts require human oversight, some minor interventions, and triggers are human-driven. No end-to-end stiching of scripts.
